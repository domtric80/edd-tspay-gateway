# TS Pay for Easy Digital Downloads 0.1.1

Release correttiva del pacchetto installabile WordPress.

## Correzione

- Lo ZIP viene ora generato con separatori POSIX (`/`), compatibili con WordPress su server Linux.
- Lo script di packaging interrompe la procedura se trova separatori Windows (`\`) o se manca `edd-tspay/edd-tspay.php`.
- Versione del plugin aggiornata a 0.1.1.

## Installazione

Scaricare esclusivamente l'asset `edd-tspay-0.1.1.zip` dalla release. Non utilizzare gli archivi automatici **Source code (zip)** o **Source code (tar.gz)** di GitHub.

Consultare la [guida completa di installazione](INSTALLAZIONE.md).
